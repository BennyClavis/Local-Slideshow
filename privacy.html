Datenschutzerklärung

Diese Datenschutzerklärung informiert Sie über die Art, den Umfang und den Zweck der Verarbeitung von personenbezogenen Daten im Rahmen der Nutzung der App Browser Diashow (nachfolgend „App“ genannt).

1. Allgemeine Informationen

Die App wird als lokale Progressive Web App (PWA) betrieben. Die Nutzung der App erfolgt direkt in Ihrem Webbrowser bzw. der PWA-Laufzeitumgebung. Alle primären Funktionen der App laufen vollständig lokal auf Ihrem Gerät ab.

2. Lokale Verarbeitung von Bilddaten

Die Kernfunktion dieser App ist die Anzeige Ihrer eigenen, lokal gespeicherten Bilddateien in einer Diashow.

  • Ordnerzugriff: Die App nutzt die File System Access API Ihres Webbrowsers. Sie wählen manuell aus, welche lokalen Ordner die App scannen darf.
  • Kein Upload: Keine Ihrer Bilddateien, Dateinamen oder Pfadinformationen werden an einen externen Server oder an den Entwickler übertragen. Der Zugriff auf Ihre Bilder erfolgt rein temporär und ausschließlich lokal in Ihrem Webbrowser.
  • Speicherung: Die von Ihnen erteilten Berechtigungen für den Ordnerzugriff sowie Ihre als „Favoriten“ markierten Bildpfade werden ausschließlich lokal in der IndexedDB (einer lokalen Datenbank Ihres Webbrowsers) auf Ihrem Gerät gespeichert. Sie können diese Daten jederzeit über die Einstellungen Ihres Webbrowsers löschen.

3. Nutzung von Drittanbieter-Schnittstellen (APIs)

Die App bietet optionale Zusatzfunktionen, die Daten aus dem Internet laden:

  • Wettervorhersage: Wenn Sie die Wetteranzeige aktivieren, ruft die App aktuelle Wetterdaten von OpenWeatherMap ab. Hierzu wird der von Ihnen eingegebene API-Schlüssel und der Name der Stadt an die Server von OpenWeatherMap übertragen. Es werden dabei keine weiteren persönlichen Daten übertragen. Die Datenschutzerklärung von OpenWeatherMap finden Sie unter openweathermap.org/privacy-policy.
  • RSS-Feeds: Wenn Sie das RSS-News-Laufband aktivieren, lädt die App Nachrichten-Feeds aus den von Ihnen konfigurierten RSS-URLs. Um CORS-Sperren im Webbrowser zu umgehen, nutzt die App standardmäßig einen Konvertierungsdienst (z.B. rss2json.com). Dabei wird lediglich die URL des RSS-Feeds übertragen, um den Feed im lesbaren JSON-Format zurückzuliefern.

4. Lokale Speicherung von Einstellungen

Sämtliche Einstellungen der App (z.B. Wechsel-Intervalle, Übergangseffekte, der OpenWeatherMap-API-Schlüssel und konfigurierte RSS-Feeds) werden über die Web Storage API (localStorage) auf Ihrem Gerät gespeichert. Diese Einstellungen verbleiben lokal und werden zu keinem Zeitpunkt an externe Server übertragen.

5. Ihre Rechte

Da wir keine Daten von Ihnen erheben, speichern oder verarbeiten, können wir Ihnen gegenüber keine Auskünfte über gespeicherte Daten erteilen. Sie haben jedoch das volle Recht, die Nutzung der App jederzeit zu beenden und alle lokal gespeicherten Daten (Favoriten, Einstellungen und Ordnerberechtigungen) direkt über die Löschfunktion Ihres Webbrowsers (Browser-Cache/Website-Daten löschen) unwiderruflich zu entfernen.

6. Kontakt

Bei Fragen zu dieser Datenschutzerklärung wenden Sie sich bitte an den Herausgeber der App (bennyclavis@gmail.com).

Privacy Policy

This Privacy Policy informs you about the type, scope, and purpose of processing personal data when using the app Browser Slideshow (hereinafter referred to as "app").

1. General Information

The app is operated as a local Progressive Web App (PWA). The app is used directly in your web browser or PWA runtime environment. All primary functions of the app run entirely locally on your device.

2. Local Processing of Image Data

The core function of this app is to display your own locally stored image files in a slideshow.

  • Folder Access: The app uses your web browser's File System Access API. You manually select which local folders the app is allowed to scan.
  • No Upload: None of your image files, file names, or path information are transferred to an external server or to the developer. Access to your images is purely temporary and entirely local in your web browser.
  • Storage: The directory permissions you grant and the image paths you mark as "favorites" are stored exclusively local in the IndexedDB (a local database in your web browser) on your device. You can clear this data at any time via your browser settings or using the "Reset App" button.

3. Use of Third-Party Interfaces (APIs)

The app offers optional additional features that load data from the internet:

  • Weather Forecast: If you activate the weather display, the app retrieves current weather data from OpenWeatherMap. To do this, the API key you enter and the name of the city are sent to the OpenWeatherMap servers. No other personal data is transmitted. OpenWeatherMap's privacy policy can be found at openweathermap.org/privacy-policy.
  • RSS Feeds: If you activate the scrolling RSS news ticker, the app loads news feeds from the RSS URLs you configure. To bypass CORS restrictions in the web browser, the app uses a conversion service (e.g., rss2json.com) by default. Only the RSS feed URL is transmitted to convert the feed into a readable JSON format.

4. Local Storage of Settings

All app settings (e.g., transition intervals, effects, the OpenWeatherMap API key, and configured RSS feeds) are stored on your device using the Web Storage API (localStorage). These settings remain local and are never transmitted to external servers.

5. Your Rights

Since we do not collect, store, or process any of your data, we cannot provide you with any information about stored data. However, you have the full right to stop using the app at any time and permanently remove all locally stored data (favorites, settings, and folder permissions) directly via your web browser's clear data function or the "Reset App" button in the menu.

6. Contact

If you have any questions about this Privacy Policy, please contact the publisher of the app (bennyclavis@gmail.com).
